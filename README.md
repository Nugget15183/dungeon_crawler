# Buried Alive
You have been buried Alive! in this game, you go through an ever-going dungeon fighting off slimes to hopefully escape!

I created this project out of inspiration from a similar game called "The Binding of Isaac", ive never played it myself, however it looked really neat and i wanted to give it a go at creating my own version!  
This game is a 2.5d dungeon game, where you go through endless dungeons to hopefully find your way out as the dungeon collapses behind you! In the dungeons you will occasionally encounter slimes who will try to end your journey, so be careful!

To play, make sure you're running windows and download the latest release .zip file from the releases page ([https://github.com/Nugget15183/dungeon_crawler/releases/tag/alpha]), once you've downloaded it, unzip it and rune the .exe!
